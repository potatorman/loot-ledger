App connection setup

Connect your shared database

Firebase config is needed behind the scenes, but your friend should not need to paste it every time. For the normal login screen, put your Firebase web config once in firebase-config.js and publish that file with the app. This form is a fallback for testing.

1
Create a Firebase project on the free Spark plan

Open Firebase Console ↗. Do not add a billing account.

2
Enable Anonymous sign-in and create Firestore

In Authentication, enable Anonymous. Create a Cloud Firestore database.

3
Publish the included security rules

Follow README.txt inside the downloaded app bundle. Rules keep room data private to its room members.

Paste the normal web app config object only. Never paste a service-account key or password. The config identifies the Firebase project; Firestore rules and room credentials control room access.
This app is designed for free-tier usage. Firebase's free quotas can change, and usage over a free limit can temporarily stop database access; billing is not needed for the setup described here.

Create a new room

Choose a room name and password. You'll become the owner and can invite up to 24 other members.

Use a strong password you can share privately with your friend. It is stored as a hash, not as plain text.

Ask the owner for the room ID and password, or open their private invite link and enter the password.
