One-time setup

Connect your shared database

The app needs a free Firebase project to keep the prices shared between devices. After setup, you and your friend use the same web app link.

1
Create a Firebase project on the free Spark plan

Open Firebase Console ↗. Do not add a billing account.

2
Enable Anonymous sign-in and create Firestore

In Authentication, enable Anonymous. Create a Cloud Firestore database.

3
Publish the included security rules

Follow README.txt inside the downloaded app bundle. Rules keep room data private to its two members.

Paste the normal web app config object only. Never paste a service-account key or password.
This app is designed for free-tier usage. Firebase's free quotas can change, and usage over a free limit can temporarily stop database access; billing is not needed for the setup described here.
